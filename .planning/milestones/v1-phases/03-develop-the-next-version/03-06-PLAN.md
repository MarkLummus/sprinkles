## What this plan is closing

`03-UAT.md` gap **G-03-9**, root causes RC1, RC2 and RC3 (the state-preservation half), plus the fifth leak the diagnosis names — the Develop button that excludes correctly but says nothing. Mark's rulings **D-UAT-1** and **D-UAT-2** govern and are not open for reinterpretation.

<flagged_assumptions>
**The route reset is implemented as a keyed remount, not as a reset effect.** D-UAT-2 requires that "pen state also resets on any route id or batchId change as a backstop". Two mechanisms satisfy that wording. A `useEffect` keyed on the parameters resets *after* a render has already happened with the previous version's pen state applied to the new version's rows — and `draftVersion` reads `penDraft.rows[row.id]` unguarded, so that one render throws whenever the two versions do not share row ids. A key on the component instance resets *before* any render. This plan takes the key.

The cost is that switching between two batches of the same version now remounts and re-reads the version and its batch list from IndexedDB, where today it does not. Both are local reads behind the repository seam and the page already re-renders wholly on that change; the reward is that the crash path and the cross-version write stop being reachable by any route at all, including the browser's own back and forward buttons, which no disabled link can guard. Recorded here rather than absorbed silently.
</flagged_assumptions>
