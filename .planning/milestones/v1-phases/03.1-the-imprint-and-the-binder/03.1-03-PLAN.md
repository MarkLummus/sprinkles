## Planner decisions recorded for this plan

1. **The Firefox calendar-icon gap is accepted and recorded, not worked around.** `::-webkit-calendar-picker-indicator { display: none }` hides the icon in Chromium and WebKit; Firefox exposes no styling hook for the native date input's calendar affordance (RESEARCH.md Pitfall 3, Open Question 1). The brief keeps the browser's own date input deliberately, for its validation and keyboard entry, so a JS date picker is refused. The WebKit rule is applied — it costs nothing in Firefox, where the selector simply matches nothing — and the gap is written into the SUMMARY and raised at the re-critique. This resolves RESEARCH.md's first open question: implement, do not silently claim the requirement fully met.
2. **Hover thickens the border and gives the difference back in padding.** D-15 asks for a thicker border on hover and the direction's carried raise forbids anything moving. Increasing `border-width` alone reflows every sibling control by a pixel, so at rest the padding carries `calc(var(--gap-xs) + var(--rule-baseline) - var(--rule-ink-field))` against a hairline border, and on hover it carries `var(--gap-xs)` against a baseline border. The sum of border and padding is identical in both states, so the box never changes size. The binder suite asserts that equality.
3. **`--gap-xs` vertical padding is applied to buttons and selects only, which is what D-16 enumerates.** Text and number fields keep the padding they have. The critique's cramped-padding finding on 21 textareas is closed by plan 04's printed-paragraph treatment, not by a blanket field-padding change here. Whether a counted field should also clear 24px is recorded as an observation for the re-critique rather than decided by a builder.
4. **`select.ink-field` needs its own padding rule.** A lone `select` selector loses the cascade to `.ink-field`, which the Step select and the citation select both carry, so the padding and chevron room are declared twice — once on `select` for any future bare select, once on `select.ink-field` for the two that exist. Plan 05 must count the chevron room when it derives the pen's wider Step column.
