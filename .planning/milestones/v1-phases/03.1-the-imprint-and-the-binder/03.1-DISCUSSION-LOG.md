### Button labels and order (free text)
**User's choice:** "Probably need to simplify names of buttons: 'Save as a new version' → 'Save as', 'Save over this version' → 'Save'; I like Cancel first on all variants." Then, to the objection that "Save as" alone leaves the object unsaid on a churned version: "If there is only cancel and save, then why not Cancel and Save? … when there are 2 save versions, the Save as and Save are fine. This is a common pattern in software." Then: "Can we drop the articles? Why do we need 'Record a batch' when 'Record batch' is fine." The other rows of the proposed label table (Develop, Record another, Amend, Add tasting, Show changes, remove/restore, add purpose, add aside, change) stood as proposed.
