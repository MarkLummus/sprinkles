## Deferred Human Verification

**Task 3 (checkpoint:human-verify, gate="blocking", LD-03) — deferred, not approved, not skipped.**

**What was built:** The pen's method now opens read-only by default, one `edit this step` text control per step revealing the step's existing fields — including the uses line and its "change" control, which opens a checklist of the recipe's rows. That checklist's own keydown handler calls `event.stopPropagation()` on Escape so the page's document-level Escape listener (which would otherwise cancel the whole pen) never fires for that key press; a second Escape, after the checklist is already closed, reaches the pen as normal. This behaviour is unchanged by this plan — only newly reachable, one click deeper than before, behind `edit this step`. Per LD-03, no jsdom interaction test was written for it (this project has no jsdom/testing-library dependency, and installing one is outside this plan's scope) — this checkpoint is the real, deferred confirmation. No dev server was started this plan.

**How to verify (reproduced verbatim from the plan):**
1. Start the dev server (`npm --prefix app run dev` from `app/`, or reuse a server already running from 03.3-01/02's own checkpoints) and open the seeded olive oil recipe's current version.
2. Open "Next version" (or "Develop") on the version row to enter the pen. Confirm the Method's steps now read as plain prose, each ending in an `edit this step` link-styled control (underlined, no border) — not the previous full form of fields.
3. Click `edit this step` on any step that uses at least one ingredient row. Confirm its fields appear (lead-in, instruction, targets, purpose/aside openers, the uses line reading "uses ...").
4. Click the uses line's `change` control. Confirm the checklist of ingredient rows opens (a list of checkboxes).
5. Press Escape once. Confirm ONLY the checklist closes — the pen itself (the version's Develop ceremony) stays open, and keyboard focus returns to the `change` control.
6. Press Escape a second time, now that the checklist is closed. Confirm this second press closes the whole pen (assuming no unsaved ink is present — if the draft is dirty, confirm instead that this second Escape does nothing, per D-24's unsaved-ink rule, and use Cancel to exit).

**Expected result (reproduced verbatim from the plan's resume-signal):** the checklist's own Escape stays scoped to the checklist alone (step 5) and a second Escape reaches the pen (step 6).
