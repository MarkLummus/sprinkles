## The figures.js structured label (separate from the thirteen)

`domain/figures.js`'s `FIGURE_SPECS[].label` changes from a plain string to `{ word, term }`. `term` is `null` for the three figures with no technical abbreviation. Settled values, `05-domain-and-language.md` cross-read against the sketch's own `FIG` array (`index.html:344-350`, which matches exactly):

| key | word | term |
|---|---|---|
| pac | "Freezing" | "PAC" |
| pod | "Sweetness" | "POD" |
| fat | "Fat" | `null` |
| msnf | "Milk solids" | "MSNF" |
| sugar | "Sugar" | `null` |
| solids | "Solids" | `null` |

A new exported pure function, `figureLabelText(label)`, flattens the shape to one string: `${label.word} · ${label.term}` when `label.term` is present, else `label.word` alone. The middle dot is the sketch's own separator (`index.html:345-348`, e.g. `'Freezing <span class="small">· PAC</span>'`) and this project's own established in-prose separator elsewhere (`formatPortionLine`'s "120 g of 370.4 g · 46.3% in all", the batch list's "2 Aug 2026 · in view") — not invented for this plan. `GraduatedRule.jsx` renders `label.word` and (when present) `label.term` as two sibling `<span>`s — never an HTML string, per this project's "notes and prose render as text, never markup" rule — and calls `figureLabelText(label)` for its own accessible-name join, replacing the current bare `label` in `[label, valuePhrase, targetText, basisText].filter(Boolean).join(', ')`. Concrete accessible-name example: a pac figure's name becomes `"Freezing · PAC, 24.1, target 22–26, estimated: Whole milk, Heavy cream, Allulose, Fine sea salt"` — same join, same commas, only the first segment changes shape.

`domain/diff.js` needs no change: its `buildDiff` already forwards `label: figure.label` opaquely (line ~219) without reading its shape, so it carries whatever `figure.label` now is without modification.
