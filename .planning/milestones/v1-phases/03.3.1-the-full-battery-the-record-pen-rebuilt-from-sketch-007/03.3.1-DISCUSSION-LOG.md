## Two save scopes' persistence contract → the one-save model

### Q: Churn-row "Save batch" with the tasting section open and ink in it — what persists?

| Option | Description | Selected |
|--------|-------------|----------|
| Batch only; tasting ink stays as draft | The churn-row save persists the batch scope; the tasting's ink stays as the unsaved draft in the still-open pen | |
| Everything on the page | One save persists whatever is on the page; the two labels stop meaning anything | |
| Batch only; tasting ink discarded | The churn-row save discards tasting ink not yet saved | |

**User's choice:** Neither — Mark redirected: "what if we went the other way and just Cancel / Save twice, one at top and one at bottom. with a single tasting per churn, then saving a churn and saving a tasting are the same action, one being more complete than the other."
**Notes:** This became D-01/D-02: one save action, two identical ceremonies, everything the record holds persists. Supersedes the sketch's decoupled saves, the save matrix and the state-based labels.

### Q: Footer "Save batch & tasting" with an empty-but-visible tasting — what persists?

| Option | Description | Selected |
|--------|-------------|----------|
| No tasting record; batch saves churn-only | An empty tasting is not a record; the state-based label can name the section while the store records nothing | |
| Empty tasting record stored | The label stays true; a dated-but-blank tasting is stored | |

**User's choice:** "perhaps save tasting button should be disabled while the tasting record is completely empty" — then dissolved by the one-save model: no separate "& tasting" button exists to disable; an empty open tasting persists nothing tasting-shaped.
**Notes:** Mark's disable idea was the seed of the save-set question that followed.

### Q: How many Cancel | Save sets should the rebuilt record pen have?

| Option | Description | Selected |
|--------|-------------|----------|
| Two sets: churn row + footer | Churn row (Cancel \| Save batch) only while the tasting is open; footer always; labels name scopes | |
| One set, foot only | The churn row's save disappears; churn-only saving needs another mechanism | |
| One set, content-true label | Label reads "Save batch" until the tasting holds something — the content-sniffing the sketch rejected | |

**User's choice:** Free-text: "with the tasting added, we have 3 save/cancel button sets on the page with potentially different meaning. that's wrong."
**Notes:** Clarified: the imprint ceremony stays retired for this pen (2026-09-12 brief revision), so the rebuild composes to two sets max; Mark then proposed the identical-pair model, which became D-01.

### Q: Where does the top Cancel | Save sit?
