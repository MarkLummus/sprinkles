# Phase 03.3.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| import file → store | A hand-edited or stale store file crosses the validator into the write path | Whole exported store JSON (versions, batches) |
| stored keys → domain maps | Stored/imported axis keys and row ids become object keys in marks and draft maps | Axis keys, row ids used as JS object keys |
| stored batch → pre-fill draft | A stored record's keys and values flow into the pen's draft state on Correct | Battery field values, marks map, defects list |
| keystrokes → save path | Every raw typed string crosses parseMeasuredDraft before storage | User-typed numeric strings |
| undo payload state → draft | A stored payload is written back onto the live record draft on restore | Tasting-body field values held in React state |
| stored marks/defects → read view | Stored values render as text in the reading state | Marks, defects, prose fields |
| dev server (localhost) → browser check | Verification drives the local app only; no network surface | N/A |
