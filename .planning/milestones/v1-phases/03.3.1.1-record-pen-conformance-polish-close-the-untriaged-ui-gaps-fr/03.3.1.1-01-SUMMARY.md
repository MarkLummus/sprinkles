### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed `cross-cutting.test.js`'s `.recipe-page` 600px-padding test broken by the new 1099.98px block**
- **Found during:** Task 1, first `npm --prefix app test -- src/styles` run
- **Issue:** `mediaRuleFor(selector)` is first-match by selector across ALL media blocks (the caveat `03.3.1.1-PATTERNS.md`'s own "cross-cutting.test.js" section documents). Once `.recipe-page` gained a rule inside the new 1099.98px block (in source order before the 600px block), the pre-existing "carries its own reduced padding in the 600px block" test's `mediaRuleFor('.recipe-page')` call started resolving to the 1099.98px rule instead, failing the `expect(rule.media).toBe('(max-width: 600px)')` assertion.
- **Fix:** Changed the test to `rules.find((r) => r.selector === '.recipe-page' && r.media === '(max-width: 600px)')`, filtering on `r.media` directly instead of relying on first-match — the same technique the plan's own Task 1 action text uses for the new 1099.98px describe block's assertions.
- **Files modified:** `app/src/styles/cross-cutting.test.js`
- **Verification:** `npm --prefix app test -- src/styles` passes (85/85)
- **Committed in:** `8c52d1d` (Task 1 commit)
