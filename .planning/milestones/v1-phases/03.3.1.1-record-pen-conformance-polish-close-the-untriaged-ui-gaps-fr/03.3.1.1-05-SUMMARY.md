# Phase 03.3.1.1 Plan 05: The redrawn save ceremonies and the record-status live region Summary

**SaveCeremony (PenFoot.jsx) grows a shared Add tasting/Restore tasting opener slot and a status live region, mounted twice (the foot and BatchRow's ceremony A) so the ninth round's Add tasting | Cancel | Save batch order and the Restore tasting takeover both read from one component; the removal toasts move from formStatus to a new recordStatus channel that lives in ceremony A**

## Accomplishments
- `PenFoot.jsx`: `SaveCeremony` gains `onAddTasting`/`addTastingRef`, `onRestore`/`restoreRef`, and `status` — renders, in order, the status paragraph (when `status` is a string), the hint, Restore tasting (when `onRestore`), Add tasting (when `onAddTasting`), Cancel, Save batch. `PenFoot`'s own record/amend branch drops its separate opener button and undo footer slot entirely, rendering only the ceremony guarded by `!tastingOpen && !pendingUndo`; the foot never renders a restore control.
- `BatchRow.jsx`: gains `onAddTasting`, `recordStatus`, `removeTastingAttempt` props and `addTastingRef`/`restoreRef` refs; a new focus effect reads `removeTastingAttempt` and `pendingUndo` to land focus on the correct control; ceremony A's mount carries `status`, `onAddTasting`, `onRestore`, both refs; the tasting head's own static undo control is rewritten from "Undo clear tasting" to "Restore tasting" on one line.
- `RecipePage.jsx`: `TASTING_REMOVED_DATA_STATUS` becomes `'Tasting removed. You can restore it.'`; a new `recordStatus` state + timer ref, cleared everywhere `tastingStatus` already is (5 sites); `announce()` gains a `target === 'record'` branch with the same guarded five-second self-clear; both removal toasts now announce with `target: 'record'`; `recordStatus`/`removeTastingAttempt` passed to `BatchRow`; `removeTastingAttempt` dropped from `PenFoot`'s mount.
- `PenFoot.test.jsx`, `BatchRow.test.jsx`, `RecipePage.test.jsx`: pins moved to the new ceremony order, the retired undo footer slot's replacement (no restore control in the foot, ever), the three-region aria-live count, the new record-status string, and the Restore tasting label.
