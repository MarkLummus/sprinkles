<assumption_delta_decision>
Detector fired (`pluralization`, term "fallback"). The real delta this phase carries: the token namespace had one implicit context — the Sheet — and now has two.

- **Noun now primary:** the *context* a token belongs to (Sheet or App), not the Sheet-as-default.
- **Decision: promote.** The generalized representation (context-prefixed names) becomes primary and the old unprefixed Sheet names are demoted to `--sheet-*`. Add-alongside was rejected: leaving the Sheet unprefixed while only the App carried a prefix would make "no prefix" mean both "shared" and "Sheet", which is the ambiguity D-02 exists to remove.
- **Invariant test accepted:** `tokens.test.js`'s prefix-discipline assertion (Task 3) goes red the moment a future phase declares a context-free Sheet token again.
</assumption_delta_decision>

<decisions_recorded>
Claude's Discretion resolved here, with the reason each choice was made:

1. **`--face-text` / `--face-grotesk` stay unprefixed** (CONTEXT.md leaves this open). The App reads both faces on nearly every rule in home.css today, and D-02 forbids the App reading a `sheet-` token except `--sheet-pen-blue`. Prefixing the faces would therefore break D-02 on the first App rule. They are shared, context-free faces until App typography is specified.
2. **The context prefix leads the name**: `--sheet-size-table-body`, `--app-size-title`. D-01 and D-03 both say the token "takes the prefix", and a leading prefix is what makes a grep for `--app-` or `--sheet-` return that world and nothing else.
3. **Where D-01 and D-02 name the same token, D-02 wins, by name family.** `--rule-strike`, `--gap-strike`, `--gap-mark-stop`, `--gap-uses-chip`, `--gap-field-unit`, `--gap-defect-col`, `--gap-select-chevron-room` are shared sizes by their family even though D-01's prose calls them strike/mark/select tokens: a 1.2px stroke and a 6px gap are context-free quantities. Splitting a family would make "read the prefix" an unreliable way to tell the two worlds apart. `--rule-width` (the graduated rule's 320px drawing width) stays unprefixed for the same reason, and its comment says so.
4. **`--offset-link-underline` stays unprefixed.** It is not in D-02's enumeration, but it has a live App consumer today (`.home__quiet`) as well as a Sheet one — exactly the shared-size rule from 03.3.1.1 ("one value app-wide"), so it is shared by that rule rather than duplicated.
5. **The folded todo takes option 2:** both derivation comment sites name `--gap-page` beside `--gap-xl`, so a grep for either finds the other. The arithmetic itself is unchanged, and it is stated for widths where `--gap-page` resolves to `--gap-xl`.
6. **The hand's four tokens keep D-17's literal names** (`--face-hand`, `--size-hand`, `--leading-hand`, `--size-hand-min`) with no `app-` prefix: D-17 names them exactly, and a locked decision outranks the naming pattern in D-03. They are listed in tokens.test.js's shared allowlist with that citation.
</decisions_recorded>
