<decisions_recorded>
1. **The visited rule loses its specificity rather than its statement.** `a:visited` (0,1,1) is rewritten as `:where(a:visited)` (0,0,0). Author-origin declarations beat the user agent's own visited colour regardless of specificity, so the Sheet's "visited reads the same as unvisited" (D-18) still holds, while every single-class App rule — `.shell__place--notebook`, `.home__action`, `.home__action--secondary` — now outranks it. Deleting the rule outright would also work (the global `a` rule would carry both states) but would leave the contract unstated in the file, and a later reader could not tell the omission was deliberate.
2. **The three Sheet-frame surfaces paint their own paper, the running-head band included.** VERIFICATION names `.recipe-page` and the not-found page; `.page-head` is added because it is the band directly above `.recipe-page` on the same route, and leaving it on the App's white would draw a visible seam across the Sheet frame. All three read `--sheet-ground`, the one colour they were already inheriting from the body rule.
3. **The header's three tool controls fold at the phone step, but the tools row itself does not.** Hiding `.shell__tools` wholesale would also hide the hidden file input and `.shell__import-errors`, so an import failure at 393px would report nothing. Only `.shell__tools > .shell__place` — the Search link and the Import/Export buttons, all duplicated inside More (D-16) — is hidden.
4. **A tab's label reads `--app-size-label` (12px), not the board's hand-copied 10px.** Sizes read tokens (the project's own convention, and DESIGN.md's "every visual value reads a custom property"); 12px is the existing micro-label role and leaves "Recipe book" about 68px wide inside the ~76px each of five `flex: 1 1 0` items gets at 393px. The 03.4-UI-REVIEW.md brief proposed the same token. Recorded as a board departure in plan 08's conformance table.
5. **More's panel carries a border and the App background, and no radius.** Board 171 draws More closed and never draws the open panel, so nothing about the panel is being copied from a drawing; the minimum that makes it legible above the bar is what ships.
</decisions_recorded>
