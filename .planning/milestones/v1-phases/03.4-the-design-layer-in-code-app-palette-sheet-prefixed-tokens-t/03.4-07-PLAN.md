<decisions_recorded>
1. **No versions count on a row, despite VERIFICATION's phrasing.** Gap 6's prose asks for "the versions count"; both authorities above it say otherwise. D-11 is explicit — "the versions word is dropped from the row" — and board 170's row (lines 86-103) has exactly five children: rod, identity, standing, tally, actions. There is no versions column to build. The board is the authority CONTEXT.md names, and the locked decision agrees with it, so the row ships without one and plan 08's conformance table records the discrepancy against the verification text so the re-verifier can see it was decided rather than missed.
2. **The rod and the tally stay at phone width, where board 171 draws neither.** DESIGN.md's App marks entry settles that the rail "stays on every list, single-destination lists included, so a row keeps one shape everywhere" (Mark, 2026-09-21), and the tally states a count UX1-03 requires in words at every width. Board 171 is read as a drawing that did not repeat them, not as an instruction to remove an approved mark. Recorded as an open departure in plan 08's table for Mark to rule on at UAT.
3. **The board's 46px lined page-preview glyph in the lead block (board 170 lines 53-58) is not built.** It is decorative, aria-hidden, absent from board 171's lead block, and absent from the four things Mark named when he listed this gap side by side with the board. Building an unrequested ornament would be scope the gap list does not ask for; it is recorded as an open row in plan 08's table instead, where it costs one line to approve later.
4. **The standing's three words are Not yet churned, Awaiting tasting and Tasted** — the words VERIFICATION names and the one the board shows ("Awaiting tasting", board line 93), in sentence case. The board's two other standings, "Ready to make" and "Saved idea", need the Recipe book and the Idea log, which lastEvent.js cannot return this phase.
5. **Sizes read tokens where the board's hand-copied pixels differ.** The board's 24px lead column gap reads `--gap-m`, its 62px lead rod and 44px row rod both read the one shared `--app-size-rail-h`, and its 13px standing reads the App meta size. The board governs structure and order; tokens govern values (DESIGN.md, and this project's shared-size rule).
</decisions_recorded>
