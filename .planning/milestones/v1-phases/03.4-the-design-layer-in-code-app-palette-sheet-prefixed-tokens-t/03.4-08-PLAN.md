<decisions_recorded>
1. **The record is written to be fillable with or without a browser.** The executor of this plan may have no browser tool. The "App shows" column is filled from the shipped source — the rule, the class and the token that decide the element — and the separate "Measured" column is filled only if the run can actually drive the app; otherwise it reads `not measured` and the probe beside it is what fills it at UAT. Recording an inferred pixel as a measured one is the failure this whole record exists to prevent.
