# Phase 03.4 Plan 15: An explicit tabindex on every app link, closing the keyboard-lockup gap's app-side half

**Seventeen `tabIndex={0}` sites across six components (RecipeList 9, RecipeHistory 3, VersionRow 2, BatchRow 1, RecipePage 1, router.jsx 1) close G-03.4-r4-1 alongside 03.4-14's shell fix, plus one recorded `.claude/CLAUDE.md` convention and an app-wide grep gate proving no Link or NavLink under `app/src` is left untagged.**

## Accomplishments

- Every one of Home's nine `Link` sites (`RecipeList.jsx`) — the empty shelf's two, the lead block's name, the three `RowActions` branches' five, and each row's name — now carries `tabIndex={0}`, pinned by two rendered-markup tests asserting exact link counts (2 for an empty store, 11 for three recipes spanning every standing, the tasted one leading).
- The recipe page's history outline (`RecipeHistory.jsx`, three sites) and the version row's two lineage links (`VersionRow.jsx`, From version and From batch) carry the same attribute, pinned by rendered-markup tests (3 and 2 links). The two pre-existing `RecipeHistory.test.jsx` literals pinning the cited-batch anchor's opening text were updated to react-router's actual rendered attribute order (`tabindex` ahead of `href`) — the only existing assertions this plan changed.
- The batch register's link (`BatchRow.jsx`), the not-found link (`RecipePage.jsx`) and the running head's link (`router.jsx`) carry the attribute — the last three of the seventeen sites. `RecipePage.jsx`'s and `router.jsx`'s sites are pinned on source text (matching the whole `Link` opening tag, one per file) rather than rendered markup, since neither can be rendered under this suite's node environment (`router.jsx`'s module-scope `document` dependency; `RecipePage.jsx`'s not-found branch is reached only after an effect that `renderToStaticMarkup` never runs).
- An app-wide gate — `grep -rn -E '<(Link|NavLink)\b' app/src --include='*.jsx' | grep -v '\.test\.jsx' | grep -v 'tabIndex={0}'` — returns nothing: no `Link` or `NavLink` line under `app/src` lacks the attribute. The built bundle carries `tabIndex:0` 27 times (Shell's 10 plus these 17).
- `.claude/CLAUDE.md` gained one Conventions bullet recording the rule, its WebKit TabsToLinks rationale, and where it is pinned — for the next component that renders a link (Phase 4's print and short-code routes).
- S2 (the keyboard dead until a power cycle) received no code change, per the plan's own decision that the app cannot cause it. The plan's `<verification>` section carries the reworded, split UAT procedure: (a) Home and (a2) a recipe page, assertable on the iPad; (b) S2, recorded through an ordered on-device recovery ladder and a neutral-page control, never asserted.
