<decisions_recorded>
1. **The step rule is plan 05's.** `isLineRemoved(row, portion, method)` and `isRowRemoved(row, method)` take the version's method as an optional third argument; absent, they read only the line's own state. This plan passes each version's own `method` and adds no rule of its own.
2. **Row-level grams and share fields in the diff are not touched.** Only `removed`, `baseRemoved` (and so `removedChanged`) on a row and `removed` on each line (plan 04's `lines`) move. The figure calls already go through `activeRows` with a full version and read the step's removal with plan 05.
3. **The blocked-save check reads the draft's method.** `penFields.method` is the pen draft's method array; the page's call passes the pen draft, which carries it (buildPenFields reads `penDraft.method`). A penFields without `method` reads as `[]`, which is how older cases build it, and behaves as before.
4. **Strictness.** Only a step's `removed === true` removes a line, and a step is found by an array scan on `n`, as in plan 05 (T-03.6-09).
5. **Measured numbers (Olive Oil v1, step n=2 'Gum slurry' removed in the saved version, none in its parent):** `diff.total.from` '799.7 g', `diff.total.to` '666.0 g'; row-10, row-11 and row-12 (the gums, one line each in step 2) removed; row-01 (Whole milk) and row-05 (Sucrose) not removed as rows, their first line removed and their second not.
</decisions_recorded>

## Trust Boundaries

| Boundary | Description |

| stored method to diff and lineage readers | A stored or imported step's `removed` and `n` decide whether a line is read as out, in Show changes and in the blocked-save check |
| maker's pen draft to saved record | A skipped amount check lets a line with no typed amount reach the save |
