# Phase 03.6 conformance: the build against decision 51's board

Probe: `.planning/phases/03.6-per-step-shared-ingredients/03.6-perstep-probe.mjs` (re-runnable: `npm --prefix app run build && node .planning/phases/03.6-per-step-shared-ingredients/03.6-perstep-probe.mjs [states] [widths] [engines]`).
Board: `.planning/sketches/011-recipe-route-c/per-step-shared-ingredient.html`; expected facts: `.planning/canvas-generators/perstep-capture.json`.

## How it was measured

- The build (`app/dist`) is served by the plan-10 harness on an ephemeral 127.0.0.1 port; the probe never touches the :4173 preview or any browser profile. Every request off 127.0.0.1 is aborted.
- Two engines, both coarse pointer: Playwright WebKit (the iPad's engine, the one the board was measured in) and system Chrome. Widths 1366 and 393. Each state is a fresh context on Olive Oil v1's route: Next version, then real clicks and fills (the 'remove Whole milk, Step 2' and 'Step 2, remove' buttons, the 'Whole milk, grams, portion 1' field), and, for the two Show changes states, 'Save as a new version' as 'v2' and the 'Show changes' button. No DOM edit anywhere.
- Facts (decision 2): the total, each Whole milk and Sucrose line's name, strike, amount, struck amount, portion line, share and link word, the step heads and the count of non-head rows, read off the live page (an input's amount is its current `.value`) and compared for equality with the capture file's `facts`. 32 comparisons per state, width and engine.
- Geometry (decision 3): where the board draws a panel for the state, the app's table and the panel's table are read on the real DOM, the board opened coarse at its own `$preview` width: each tbody row's height, each remove or restore link's width and height, each struck value's computed `text-decoration-line` and colour. Rows and links and struck values are compared in order, within 1px for sizes and exactly for the decoration and colour.
- Access: every `button` in the pen's ingredient table has the attribute tabindex `0`; each struck line's accessible name (its row's aria-label) ends with `removed` and its link, when it has one, reads `restore`.
- The state map: resting is `rest`; the Step 2 milk line out is `z_wm2` (board panel `fp-step-a`); the Step 3 milk line out alone is `z_wm3` (`fp-step-c`); both milk lines out is `b_wm2` (`fp-step-b`, 1366 only; the board's own build page after one press, which decision 51 says is the same page as both lines out, so the probe presses both lines); the edit is `p_edit` (`fp-amt-b`, 1366 only); the step removed is `z_step2` (`fp-rm-b`); Show changes after the edit is `p_show_edit` (`fp-sc-b`, 1366 only); Show changes after the line removal is `p_show_rm` (`fp-scr-b`, 1366 only).
