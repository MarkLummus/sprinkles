## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Imported store file to the store | A JSON file Mark imports can carry a line's or a step's `removed` flag, ids and method arrays | Local recipe data (versions, batches); no secrets |
| Stored flags to the domain | `rows.js`, `lineage.js`, `diff.js` read stored removal flags and row ids | Booleans, row ids, step numbers |
