## Task order and the measured findings

- The tracer gate: `<verify>` is automated only and `human_verify_mode` is end-of-phase, so the end-to-end checks (suite, build, `screen`, `print P1`) were re-run on the proven slice before Task 2; they passed.
- Measured while building: at 56px side margins the letter page is 704px wide, so the phone-forms block (max-width 723.98px) applied in print and the list form hid the table's head. That is the reason for the screen-only block, which is a true no-op on screen.
- Measured: P5 and P7 failed before the Task 2 rules (the Total printed alone on page 2 with the repeated header while Step 8 stayed on page 1; the heading alone at the foot) and pass after. P6's page 1 ended on "INGREDIENTS" alone before the rule.
- P1-K1, P2 and P3 already passed after Task 1: Chrome's default splits a lone group between rows and the Instructions already flowed after the tail, so the `.method-step` rule is the guarantee the board asked for rather than a visible change on Olive Oil v1. No seeded version has a step crossing a foot in these cases.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] The build is served from a scratch directory, not app/dist**
- **Found during:** Task 1, step (1)
- **Issue:** The harness's `startServers()` serves `REPO_ROOT/app/dist`, and the orchestrator forbids writing `app/dist` (Mark's `vite preview` serves it).
- **Fix:** `startServers({ appRoot })` takes an optional directory (default unchanged); the probe reads `PROBE_DIST` (default `app/dist`). Verification ran on `--outDir` builds in the scratchpad.
- **Files modified:** `.planning/phases/03.5-separate-the-recipe-from-the-sheet/03.5-probe-harness.mjs`
- **Commit:** e49ffa2

**2. [Rule 3 - Blocking] pdf-pages.swift truncated a page's text at 2000 characters**
- **Found during:** Task 1, step (2)
- **Issue:** Olive Oil v1's second page carries more than 2000 characters, and the case needs every step's lead-in and tail.
- **Fix:** a second argument `all` prints a page's whole text; any other second argument still prints 2000 and none prints 700, as before. Still the tracked file, compiled into the OS temp dir.
- **Files modified:** `.planning/canvas-generators/pdf-pages.swift`
- **Commit:** 9782cff
