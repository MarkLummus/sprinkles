Close gap G-03.3.1-4 from 03.3.1-UAT.md: the tasting read view's `<h3>` caption
duplicates the exact word-and-stop tokens ("soft (2) · gummy (4) · ...") that
the `.batch-row__cells` grid immediately below it already renders, at the same
visual weight (no differentiating CSS exists). Mark rejected this in UAT test

renders it inside the `<h3>`.

("the read-view summary line... belongs to the batch read view, not the pen")
per Mark's more recent, explicit UAT rejection — the two renderings never
shared code, only the same source data, and the duplication is unwanted.

Purpose: a maker rereading a saved tasting sees each axis's word once, in the
cell grid, not twice.

(marked or unmarked); `BatchRow.test.jsx` is updated to match.
