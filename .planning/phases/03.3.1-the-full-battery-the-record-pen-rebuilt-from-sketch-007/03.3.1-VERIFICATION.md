## Note on the roadmap goal's "decoupled churn/tasting saves" phrase

Unchanged from the prior verification. The ROADMAP.md goal text (written before phase discussion) says "decoupled churn/tasting saves." This is superseded by an explicit, recorded, Mark-approved mid-discussion decision (03.3.1-CONTEXT.md D-01–D-06): the sketch's decoupled two-scope save model was replaced with **one save action, repeated as two identical ceremonies**. This is documented as the phase's "biggest fact" in CONTEXT.md and is honored consistently in the shipped code (`PenFoot.jsx`'s `SaveCeremony`, mounted twice, identical markup and label). Not a gap — a legitimate, human-approved design change.
