- [ ] CONSTRAINT: The sketch HTML is the single authority (007 @ `109733d`, 003 @ `59f7948`, 008 @ `0fa1015`). Never answer an app-vs-sketch difference with an accepted-departure row.
- [ ] CONSTRAINT: Measure, never reason from CSS source — and **measure in the engine that matters**. This session's hardest lesson: every remaining defect was found by Mark on an iPad and missed by headless Chromium.
- [ ] CONSTRAINT: Do not make design-system-wide changes inside a conformance pass. Two regressions this session came from exactly that.

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Departure rows | Treating a sketch-vs-app difference as accepted | blocking | Every difference goes to Mark as a sketch edit |
| Frame-width presets | Judging phone sizes with a toolbar preset | blocking | Real viewport emulation only |
| Verifying in the wrong engine | Confirming a WebKit-only defect against Chromium, or in a probe page instead of the app | blocking | A device-only defect is verified on the device, in the real app, before it is called fixed |
| Widening a media query without checking what rides it | `(pointer: coarse)` carried track GEOMETRY into a desktop grid and overlapped the axes | blocking | Separate SIZE rules from GEOMETRY/LAYOUT rules; layout stays width-keyed |

<decisions_made>
- Touch is a MODE, not a width. Sketch 008 lines 162-167 already carry the rule as a `.touch` class; `syncTouch()` fakes it by width only because a static sketch has no pointer to query. The app had implemented the simulation instead of the rule — so SR-1..SR-5 were an app gap, not a sketch round (this corrected an earlier wrong call in this session).
- Touch mode in the app = `(max-width: 759.98px), (pointer: coarse)` — a union, so a narrowed desktop window still exercises it for testing (Mark, so he can test without the iPad).
- SIZE rules may ride the pointer; GEOMETRY and LAYOUT rules may not. The version-row collapse (D-15/I-01) and the axis track geometry both stay width-keyed.
- The Source column drops at phone width rather than the ingredient table scrolling — deferred to a sketch session (Open Question 4).
- Shared size tokens hold one value app-wide; split only for a named exception.
