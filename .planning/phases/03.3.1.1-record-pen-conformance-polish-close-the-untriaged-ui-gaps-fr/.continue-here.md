## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Departure rows | Treating a sketch-vs-app difference as "known, accepted" in CONFORMANCE.md instead of redrawing the sketch | blocking | D-22 aims at zero departure rows; every difference goes to Mark as a sketch edit, measured and shown before commit |
| Frame-width presets | A sketch toolbar that narrows the frame does not fire media queries; sizes looked wrong to Mark at "393" | blocking | Judge phone widths only at a real viewport (gsd-browser `browser_emulate_device`) or with the sheet's `syncTouch` class; never trust a preset alone |
| zsh echo of JSON | `echo "$INIT"` in zsh mangles `\\` escapes in gsd-tools JSON and breaks `JSON.parse` | advisory | Run GSD init/query pipelines from a `bash` script file with `printf '%s'` and `node -e` |
| Line drift under research | Editing a sketch while a researcher cites it by line | advisory | Keep edits line-stable (append to existing lines, use blank lines) or re-cite afterwards |
| Stale tab | Mark reviews in his own Chrome tab; the sketch server sends no cache headers, so his tab showed an earlier file and a fix "didn't take" | advisory | Ask for Cmd+Shift+R (or name the `?r=N` URL) and verify the rule via computed style in the MCP tab before changing code |
| Script focus after a mouse click | Chrome shows no `:focus-visible` on an element focused by script right after a pointer click; Clear's focus move looked like focus skipping the first cell | advisory | Move focus programmatically only from keyboard-initiated actions (`event.detail === 0`); let the browser's tab position handle the mouse case |
