# Phase 03.4 Plan 6: The shell's world — App ground, zero-specificity visited rule, a typed placeholder, a phone-fit tab row Summary

**Closed the four gaps living in the shell's own world: `.shell` now paints the App ground for every route (retiring home.css's route-only rule), the three Sheet frames paint their own paper behind it, `a:visited` is rewritten `:where(a:visited)` so no single-class App rule loses its colour to a visited link, `Placeholder.jsx` gets the `.place`/`.place__title`/`.place__note` rules its own file already promised, and the bottom tab row is rebuilt to fit 393px — five `flex: 1 1 0` items, icon over label, More opening as a panel above the bar.**

## Performance

- **Completed:** 2026-09-22T02:43:08Z (Task 3 commit)
- **Tasks:** 3 completed
- **Files modified:** 7

## Accomplishments

- `.shell` declares `background: var(--app-background)`, so every route the shell wraps sits on the App's own ground instead of only the Home route painting it for itself. `home.css`'s route-level `body:has(.home)` rule and its justifying comment are retired.
- `app.css`'s three Sheet-frame surfaces — `.recipe-page`, `.page-head` and `.not-found` — each declare `background: var(--sheet-ground)` explicitly, keeping the paper world's own colour now that the blanket `body` rule no longer reaches them behind the shell.
- `app.css`'s `a:visited` becomes `:where(a:visited)`: the same declaration, zero specificity, so single-class App rules (`.shell__place--*`, `.home__action`, `.home__action--secondary`) can no longer be dragged to Sheet ink once a route has been visited. The Sheet's own "visited reads the same as unvisited" contract (D-18) is unchanged.
- `Placeholder.jsx`'s root gains the `place` class; `shell.css` writes `.place`, `.place__title` (mirroring `.home__title`'s role exactly) and `.place__note` (the App meta size in the secondary text colour), so six of the app's ten routes render in the App's own type instead of user-agent defaults.
- The bottom tab row is rebuilt entirely inside shell.css's one existing media block: the bar is pinned to `--app-size-tab-h` with border-box sizing; the five flex children (four destination links plus the More disclosure) each take `flex: 1 1 0; min-width: 0`; each tab lays out icon over label; More opens as an absolutely-positioned panel above the bar; and the header's Search/Import/Export controls fold away below the phone step while the tools row itself (the shared file input, the import-errors list) stays unhidden.
- Full suite: 1104 passed, 0 failed (up from 1095 at plan start — 9 new tests). Build succeeds, 126 modules transformed. `grep -c "@media"` returns 1 for both `shell.css` and `home.css` — neither file grew a second condition.
