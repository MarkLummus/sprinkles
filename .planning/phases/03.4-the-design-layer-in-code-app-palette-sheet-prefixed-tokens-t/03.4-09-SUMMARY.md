# Phase 03.4 Plan 09: Three chrome-level UAT gaps closed — the per-context canvas, the rail's edge, and a focus fallback for a modality boundary WebKit never crosses

Closed G-03.4-9 (cream rubber-band on every App route on iOS), G-03.4-7 (the rail's missing padding and right border), and G-03.4-4 (no focus ring on Mark's iPad with Full Keyboard Access on) — each root-caused in its own debug session before this plan, each closed with a one- or two-declaration fix and a pinning test.

## Performance

- **Duration:** ~20 min
- **Tasks:** 3
- **Files modified:** 5 (app.css, binder.test.js, shell.css, shell.test.js, 03.4-GAPS-CONFORMANCE.md)

## Accomplishments

- **The canvas per context (G-03.4-9):** `body`'s background became `var(--app-background)` (the element the UA propagates to the CSS canvas iOS Safari paints during elastic overscroll); a new `body:has(.recipe-page, .page-head, .not-found)` rule hands the canvas back to the Sheet's cream for the three paper frames. `html` stays unstyled, deliberately — a background there would cancel the propagation entirely (measured in the debug session). This replaces the guard commit 4105848 deleted alongside the App ground it retired.
- **The rail's own edge (G-03.4-7):** `.shell__rail` gained `box-sizing: border-box`, a padding reading the gap scale (`6px 20px 32px 20px`, board 170's own hand-copied `8px 20px 32px 30px` read through tokens per 03.4-07 decision #5), and a hairline `border-right` reading `--app-rule-row`/`--app-divider`. The rail's declared 224px basis is unchanged. Conformance row 3 rewritten from `differs` to `matches`.
- **A focus ring for a modality boundary WebKit never crosses (G-03.4-4):** one new `.shell__place:focus` rule, scoped narrowly to the shell's own stops (tools row, rail, tab row, and More's summary — all share this class), mirroring the project's own documented `.is-landing-focus:focus` exception for the same class of problem. No new media condition — shell.css still carries exactly one.
- Three new pinning tests (binder.test.js gains one describe block with three assertions; shell.test.js gains two describe blocks with six assertions total), so none of the three fixes can be silently retired the way commit 4105848 retired the canvas guard without a test catching it.
