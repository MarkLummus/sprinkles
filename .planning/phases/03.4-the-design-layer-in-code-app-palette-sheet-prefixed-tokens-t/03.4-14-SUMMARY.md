# Phase 03.4 Plan 14: Every shell stop pinned to an explicit tabindex, and the falsified focus-lands premise corrected

**Ten `tabIndex={0}` JSX sites (nineteen rendered `shell__place` stops) bypass WebKit's TabsToLinks/Full-Keyboard-Access gates so Tab can reach the shell on Mark's iPad, plus a corrected `shell.css` comment and a dated 03.4-09 record correction that stop citing round two's falsified "focus lands" inference as measured.**

## Accomplishments

- Every `shell__place` element in Shell.jsx — the tools row's Search/Import/Export, the rail's Home and its five `RailPlace` destinations, the tab row's Home and its three `RailPlace` destinations, More's summary, and the three `RailPlace`/Search/Import/Export items inside More — now carries `tabIndex={0}`, from ten JSX sites rendering nineteen stops. The hidden file input's `tabIndex={-1}` is untouched.
- A new `Shell.test.jsx` describe block pins the rendered markup, not the source: exactly 19 `shell__place` opening tags (`<a>`, `<button>`, `<summary>`) each carry `tabindex="0"`, and `tabindex="-1"` occurs exactly once, on the `type="file"` input alone.
- The shell's own comment above `export function Shell()` gained a prose explanation of why — WebKit routes an element with an explicit tabindex past the TabsToLinks and Full-Keyboard-Access gates straight to `Element::isKeyboardFocusable` — written so the acceptance criterion's `tabIndex={0}` grep count stayed exact at 10 (the phrase reads "an explicit tabindex" in prose, never as the JSX attribute).
- `shell.css`'s comment above `.shell__place:focus` was rewritten to state the round-three finding: the round-two "focus lands without `:focus-visible`" reading was an inference, never measured; round three showed focus never entered the page at all; the rule stays as the ring for when focus does arrive. The rule's selector and declarations are byte-for-byte unchanged.
- `03.4-09-SUMMARY.md` gained one dated `## Correction — 2026-09-22 (G-03.4-r3-3)` section, placed after the lead paragraph and before Performance; its frontmatter, key-decisions, coverage and accomplishments are untouched.
