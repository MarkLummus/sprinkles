# Phase 03.4 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| repository source -> browser bundle | Build-time constants (tokens, stylesheets) compiled into the CSS bundle | none at runtime |
| third-party font distribution -> repository | One vendored woff2 binary and its licence enter the repository | binary font file |
| app origin -> browser font loader | The face is fetched from the app's own origin only | font request |
| a chosen file -> the local store | A maker-picked JSON file is parsed and validated before reaching IndexedDB | maker's own recipe data |
| stored record -> the DOM | Recipe names, place names and the maker's Next time render on Home and the recipe page; any may have arrived through an import | maker-authored text |
| stored record -> the domain helper | Timestamps and batch shapes reach pure functions | timestamps, batch records |
| the URL -> the router | A typed or bookmarked path reaches the layout route | path string |
