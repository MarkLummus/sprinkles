## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] The "no v2" test asserted too broadly across all recipes, not just Mexican Chocolate**
- **Found during:** Task 3, RED phase for Pineapple/Coconut
- **Issue:** Task 2's RED addition asserted "no exported version id or versionLabel names v2" over *every* version in `transcribedRecipeGroups`. D-01's "no v2 made up" rule is specific to Mexican Chocolate's own missing binder page — Coconut legitimately has a v2 (Coconut v1 → v2 is explicitly required by decisions_recorded 1). Once Task 3 added `coconutV2`, this test began failing on entirely correct data.
- **Fix:** Scoped the assertion to the Mexican Chocolate group only (`transcribedRecipeGroups.find((g) => g.recipe.id === 'mexican-chocolate')`), with an updated test name explaining why Coconut is exempt.
- **Files modified:** app/src/data/seed-recipes.test.js
- **Verification:** Full suite green after the fix; the corrected test still catches a genuine Mexican-Chocolate v2 if one were ever added.
- **Committed in:** 1a443cf (Task 3 test commit)

**2. [Rule 1 - Bug] The states-coverage test read `standingFor` at the wrong granularity**
- **Found during:** Task 3, GREEN phase, after all three recipes' data existed
- **Issue:** The first draft called `standingFor(group.batches)` once per *recipe* (3 groups), matching `activeWork()`'s real usage (one standing per recipe, from its newest batch). But with 3 recipes and each recipe's newest-by-churn-date batch happening to carry a tasting, the recipe-level standings were `['tasted', 'tasted', 'tasted']` — never surfacing `not-yet-churned` or `awaiting-tasting`, even though those states genuinely exist in the data (Mexican Chocolate v4 has no batch at all; v3's and Coconut v2's batches have no tasting). D-05's coverage claim (decisions_recorded 2) is stated per *version*, not per recipe's aggregate standing.
- **Fix:** Rewrote the test to compute `standingFor` once per *version*, filtering `batches` to that version's own `versionId` first. This correctly surfaces all three standings (Mexican Chocolate v1/Pineapple v1/Coconut v1 → tasted; Mexican Chocolate v3/Coconut v2 → awaiting-tasting; Mexican Chocolate v4 → not-yet-churned).
- **Files modified:** app/src/data/seed-recipes.test.js
- **Verification:** Test passes; the States coverage table in `03.5-SEED-REVIEW.md` independently documents the same seven states/sources by hand, cross-checked against the test's own per-version reading.
- **Committed in:** 41ebe28 (Task 3 feat commit)
