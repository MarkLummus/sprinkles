# Phase 03.5 Plan 05: Replace the nested History outline with sketch 011's dated rail Summary

## Accomplishments

- `app/src/domain/historyRail.js` (new) — `railEntries(versions, allBatches, { currentVersionId, draft })`: orders a recipe's versions oldest-first (the retired tree's own ascending, undated-last comparator), computing `churned`/`inView`/`latest` and a combined `stateWords` string (`versionIdentity`/`dayMonthWords`/`latestChurnDate`, all reused unchanged from the existing domain layer), plus a trailing draft entry when given. `railHint(count, { belowDesktop, overflowing })` composes the caption's hint text.
- `app/src/domain/batch.js` — `dayMonthWords(iso)` -> `'D Mon'`, built on `formatRecordDate`'s own month table, `'date unknown'` when absent.
- `app/src/ui/RecipeHistory.jsx` rebuilt — a flat `.notebook-history` rail: caption + hint, a hairline track, an `<ol>` of nodes (date/mark/name/state spans), each a `Link` (tabIndex 0, `notebookPath`) or a `<span>` (current or pen-open, `aria-current="page"`). A layout effect sets the rail's own `scrollLeft` to the in-view node (never `scrollIntoView`), measures overflow for the hint, and tracks `scrollLeft > 0` for the left fade. `versionForest`, `chainTerminates`, `BatchAttempt`, `VersionNode` and `tastingOutcome` are gone.
- `app/src/ui/useBelowDesktop.js` (new) — `useBelowDesktop()`/`BELOW_DESKTOP_QUERY` (`'(max-width: 1499.98px)'`), a node-guarded `matchMedia` hook copied from `BatchRow.jsx`'s `useBelow760`.
- `app/src/ui/VersionRow.jsx` — the History disclosure/panel, `historyOpen` state and the `HistoryDisclosure`/`HistoryPanel`/`RecipeHistory` imports are gone; the version column no longer owns the rail.
- `app/src/ui/RecipePage.jsx` — renders `<RecipeHistory>` directly inside `.notebook-band`, after `.notebook-band__grid`; `penOpenedAtRef` (a ref, never stored) holds the pen's own open time, set in `handleStartDeveloping` and cleared in `handleCancelDeveloping` and both save handlers' success paths; `draft` is computed from `mode`/`penDraft`/`penOpenedAtRef.current` and passed straight through.
- `app/src/styles/notebook.css` — the rail's rules value-for-value from `1600-batch.html`/`1600-long-history.html`: the 168px/24px-gap nodes, the 27px track, the three mark states (hollow / hollow+ring / filled+ring), 14px/20px names at 400/700, 12px/16px date/state lines, and the 96px left fade gradient (`transparent` → `--app-background`).
- `app/src/styles/tokens.css` — 12 new `--app-notebook-history-*` tokens for board values with no existing role to reuse; the mark colour reuses `--app-notebook`, its hollow border `--rule-baseline`, the track `--app-rule-row`. `--sheet-rhist-vname-min` and `--sheet-size-version-line` retired (their only reader, the deleted `.recipe-history__version-name` rule, is gone).
- `app/src/styles/history.css` — every `.recipe-history*` selector and the `--records`/`--branches` nesting rules deleted (nothing renders them now); `.history-list`/`.history-item`/`.history-register*`/`.history-provenance` kept, since `BatchHistoryPanel` (`BatchRow.jsx`) still reads them.
