<decisions_recorded>
1. **Folds read one media answer.** RecipePage calls useBelowDesktop() once and passes `foldable` down, as AxesGrid takes an explicit `below`. Node tests render both arrangements without stubbing matchMedia.
2. **Fold labels.** The boards draw the closed state only: 'Details', 'Show balance and things to check' and 'Show'. Details keeps its noun. The two 'Show' controls read 'Hide …' while open, with aria-expanded carrying the state as well. Listed in Open for Mark.
3. **The Balance heading.** 1366-batch.html renders the 'Balance' h2 outside the fold and the rules inside it. The region renders the h2 at every width and FormulationNote renders none (showHeading false), so the heading's place never depends on width.
4. **How the boards are viewed.** Boards are served from the repo root with `python3 -m http.server 8011` (the README's own instruction, which makes the font path resolve), never through Vite. Each board is viewed in a viewport of its own width, because an artboard gets no viewport of its own. 393 uses device emulation, not a window resize, which does not move the viewport. The app is viewed from the built preview in a browser that has already visited the routes, so :visited styling is live.
</decisions_recorded>
