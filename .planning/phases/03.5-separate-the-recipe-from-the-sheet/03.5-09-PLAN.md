<decisions_recorded>
1. **A decision gate, not a verify gate.** This project runs `human_verify_mode: end-of-phase`, which turns planner-emitted human-verify checkpoints into end-of-phase checks. D-07 requires the stop before wiring, so the gate is a checkpoint:decision with gate="blocking-human", which no mode auto-approves. It leads the plan by necessity; the tracer is the first implementation task after it.
2. **A second DB bump.** Plan 01 moved DB_VERSION to 6 for the recipes store. The seed's content changes here, and seedIfEmpty writes only into an empty store, so a profile seeded at 6 would never receive the new recipes. Moving to 7 uses D-10's own reset mechanism. There is no real data (D-10).
3. **Olive oil first.** Its group is listed first, so the store's first-written records stay the working case, and Home's order still comes from recency (activeWork).
</decisions_recorded>
