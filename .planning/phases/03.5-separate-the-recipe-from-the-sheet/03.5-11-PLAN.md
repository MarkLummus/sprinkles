<decisions_recorded>
1. **Task 1 is wide by necessity.** The "Ingredient" head is shared by every mode. Once it spans two columns, every render path and the total row must emit the amount cell in the same commit, or assertCellCountsAgree turns the suite red. The list form ships with the column form because the list's first track is the only remaining reader of --sheet-plan-grams-w, and tokens.test.js fails on a declared token nothing reads.
2. **Content-sized columns use the board's idiom:** `width: 1%` with `white-space: nowrap` on the amount and numeric cells, in an auto-layout table. The name column stays the one `width: auto` column. `1%` is a layout keyword-like value, as the file's many `width: 100%` are, not a visual value, so it takes no token.
3. **The span stays.** GramsCell keeps rendering `.ingredient-table__plan-grams` (the pen's field and the struck parent depend on it), now inside the amount cell. The span's rule keeps only `white-space: nowrap`: alignment and the 18px gap before the name move to the cell, as 1366-batch.html draws them.
4. **The portion line loses its indent.** It sits in the name column now. The boards draw it flush with the name (no padding-left), so --sheet-portion-indent retires.
5. **The list form uses the board's selectors without `!important`.** As made is the numeric cell second from last and the share the last. That position is unambiguous in both states: with no batch the row has three cells and no numeric cell is second from last. The class guard `td.ingredient-table__col-numeric` keeps a positional rule from reaching the name.
6. **Undrawn states are measured, not styled from imagination.** The pen is drawn (1600-pen.html) and compared. The recording state's as-made field is not drawn: if the content-sized column squeezes it below the table's one drawn grams-field width (--sheet-grams-field-w, 52, 1600-pen.html), it takes that width, and the choice is listed for Mark. A marked row's bold weight may now nudge content-sized columns, against DESIGN.md's "nothing changes position". The probe measures the shift and the SUMMARY reports it for plan 14's Open for Mark. No fix is invented here.
</decisions_recorded>
