<decisions_recorded>
1. **A new step is recognised by `stepDiff.textFrom == null`.** That is the only shape buildDiff gives a step whose `n` is absent from the parent. Every struck-beneath treatment (lead-in and instruction, purpose, aside) is gated on `textFrom != null`, because a new step has no parent text to strike. Null-chaining the reads alone is not enough: the debug note measured that it still emits three empty struck paragraphs.
2. **The margin number and the target chips are untouched.** displayNumberFor(step) already prints a current-frame number unmarked. The target chips already guard `targetDiff.from != null`.
3. **The probe is a new file** (`03.5-changes-probe.mjs`, group `changes`) built on the plan-10 harness, so this plan shares no file with the other plans in its wave.
</decisions_recorded>
