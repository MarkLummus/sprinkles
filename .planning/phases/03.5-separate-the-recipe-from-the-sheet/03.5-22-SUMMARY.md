# Phase 3.5 Plan 22: As-made field, foot ceremony and Home link sizes Summary

**The recording as-made field now holds 56px while digits are typed (the live total is inline-size contained so it stops sizing the column), the foot band's ceremony is one right-aligned column that never breaks a button label from 983 to 1600, and Home's recipe-name links are 44px inline-flex targets under a coarse pointer.**

## Accomplishments

- **G-03.5-8a (tracer).** The field's width came from a chain: `.ink-field` is 100%, the numeric column is content-sized, and its widest nowrap content was the tfoot's live total, recomputed on every keystroke. The field now carries `ingredient-table__as-made-field` (56px, two classes so it beats `.ink-field`), and the recording total cell carries `ingredient-table__live-total`, whose `.sheet-hand` is `display: flex; justify-content: flex-end; contain: inline-size`. The total stays in flow (a block the width of its cell, right-aligned), which is why no override was needed in the 723.98px list form: an out-of-flow total would have collapsed that grid row. The reading state, the pen's grams column and the list form's track are unchanged.
- **G-03.5-8b.** DESIGN.md 362 and 482 changed first. `.pen-foot` is one `1fr` track, `.pen-foot__controls` spans it (`grid-column: 1 / -1`), the 983.98px block's two foot rules are gone, and `.save-ceremony button` is `flex: none; white-space: nowrap`. The log's wrap rule and the 723.98px wrap rule are untouched.
- **G-03.5-4b.** DESIGN.md 376 names Home's recipe-name links first in the coarse floor's list. `home.css` gains a third top-level media step, `@media (pointer: coarse)`, giving `.home__name a, .home__lead-name a` `display: inline-flex; align-items: center; min-height: var(--touch-min)`. No link joined app.css's coarse union (its six-selector pin is untouched).
- **Probes.** `recording` now types '12345' into a fresh field and appends '999' to a saved one, reading the field, its cell, the name cell and the row's grid tracks after each key. New `ceremony` group opens the Record and Correct pens at nine fine widths plus 1024 and 1366 coarse and reads every `.save-ceremony` (labels on one line via a Range, buttons overlapping in height, the foot's controls as wide as the foot). New touch-probe `home` group measures every name link, hit-tests 2px inside its top and bottom edges, and hit-tests 3px inside every visible action's top.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Live-total hook broke columns.test.js**
- **Found during:** Task 2 (a full test run; my Task 1 run had only shown the tail of the output)
- **Issue:** the first hook name, `ingredient-table__col-numeric--live-total`, sits in the `ingredient-table__col-*` namespace that `columns.test.js` reads as column identities, so two tests failed (the component emitted a fourth "column").
- **Fix:** renamed to `ingredient-table__live-total` in the component, its test and the CSS.
- **Files modified:** app/src/ui/IngredientTable.jsx, app/src/ui/IngredientTable.test.jsx, app/src/styles/app.css
- **Commit:** `f046cf0`

**2. [Rule 3 - Blocking] The probe's ceremony row check and the caret**
- **Found during:** RED authoring
- **Issue:** the plan says buttons "share one top (±1)", but the ceremony aligns on the baseline, so a text control's top differs from a bordered button's even on one row (983 failed). Separately, macOS's End key scrolls rather than moving the caret, so the "append" series typed into the middle of the saved value.
- **Fix:** the row check is now "every button's vertical span overlaps every other's"; the caret is set with `setSelectionRange`. Both are probe-only.
- **Commit:** in the RED commits `da206cc` and `8be3075`

**3. [Rule 1 - Mechanism] Total kept in flow, not positioned**
- decisions_recorded 2 offered "positioned out of flow" as an example. `contain: inline-size` achieves the same (zero contribution to the column's width) while keeping the total in flow, so the list form below 724 needed no override and no change to the pinned 723.98px rule list.

**Total deviations:** 3 (1 bug, 1 blocking probe fix, 1 mechanism choice within the plan's latitude). **Impact:** none on scope.
