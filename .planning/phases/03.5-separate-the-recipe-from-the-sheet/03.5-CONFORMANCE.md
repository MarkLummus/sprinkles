# 03.5 Conformance Record

The built app (`npm --prefix app run build && npm --prefix app run preview`,
commit `ed5a313`) read against sketch 011's boards, element by element, in a
real browser — the check project lessons 03.3.1 and 03.4 both name as the one
no prose or test count replaces. Every row below is taken from the JSON
readings this run's own probe (`03.5-conformance-probe.js`) produced,
committed as evidence under `03.5-conformance-readings/`; no row here is
judged from source. `w`/`h` are `getBoundingClientRect()`; `fs`/`fw`/`ff`/
`color`/`bg`/`br`/`gap` are `getComputedStyle()`. Positions (`top`/`left`)
are not compared row by row — the two pages carry different content above a
given element (a live "churned 2 Aug" date line the board hand-writes once,
for one) — except where a position difference is itself the finding.

Two probe bugs, both a document-wide selector reaching past the element it
meant to scope to, are fixed in this run (`2fc1083`) and noted per affected
row below as **probe fixed, re-measure pending** — this run cannot re-open a
browser to confirm the corrected reading; the orchestrator's own re-run after
merge is where that happens.

Two real CSS drifts are fixed in this run (`3d5f2aa`, `5bc9cbf`) and noted
per affected row as **fixed, re-measure pending**, for the same reason.
