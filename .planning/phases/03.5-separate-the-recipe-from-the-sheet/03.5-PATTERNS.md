### `app/src/store/db.js` (config/store-schema, CRUD)

**Analog:** itself (`app/src/store/db.js:1-38`) — this is the pattern to extend, not a different file to copy from.

**Full current shape:**
```js
export const DB_NAME = 'sprinkles';
export const DB_VERSION = 5;

export function openStore() {
  return openDB(DB_NAME, DB_VERSION, {
    upgrade(db, oldVersion, newVersion, transaction) {
      if (oldVersion > 0 && oldVersion < DB_VERSION) {
        if (db.objectStoreNames.contains('versions')) db.deleteObjectStore('versions');
        if (db.objectStoreNames.contains('batches')) db.deleteObjectStore('batches');
      }
      if (!db.objectStoreNames.contains('versions')) {
        db.createObjectStore('versions', { keyPath: 'id' });
      }
      if (!db.objectStoreNames.contains('batches')) {
        const batches = db.createObjectStore('batches', { keyPath: 'id' });
        batches.createIndex('by-version', 'versionId');
      }
    },
  });
}
```

**03.5 change:** bump `DB_VERSION` to a fresh number (e.g. 6); add `'recipes'` to the drop-loop condition and a third guarded block: `if (!db.objectStoreNames.contains('recipes')) { db.createObjectStore('recipes', { keyPath: 'id' }); }` — no index, D-11's shape has no secondary lookup key. Preserve the ordering comment (drop-before-create is load-bearing) and extend it to mention `recipes`.

**Testing pattern:** no `db.test.js` exists yet — write one against `fake-indexeddb` (already a project dependency per STATE.md's Phase 3 precedent) proving the upgrade creates all three stores from a fresh DB and from an `oldVersion` predating `recipes`.

### `app/src/store/transfer.js` (service, transform + CRUD)

**Analog:** itself — `validateAuthoredNote` is the closest existing validator shape for a small flat-field object; `validateVersion`/`validateStoreFile`'s `$.versions`/`$.batches` blocks are the pattern for adding `$.recipes`.

**Validator pattern to copy** (`transfer.js:146-157`, `validateAuthoredNote` — closest shape to a 3-field flat record):
```js
function validateAuthoredNote(note, path, errors) {
  if (!isPlainObject(note)) {
    errors.push(`${path}: expected an object`);
    return;
  }
  if (typeof note.text !== 'string') {
    errors.push(`${path}.text: expected a string, got ${JSON.stringify(note.text)}`);
  }
  if (!isStringOrNull(note.inheritedFrom)) {
    errors.push(`${path}.inheritedFrom: expected a string or null, got ${JSON.stringify(note.inheritedFrom)}`);
  }
}
```
New `validateRecipe(recipe, path, errors)` follows this exactly: `id` via `isNonEmptyString`, `name`/`description` via `typeof === 'string'` checks (mirroring `validateAuthoredNote`'s `.text` check).
