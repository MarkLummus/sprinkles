## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| chosen file -> local store | A maker-picked JSON file is validated by transfer.js before reaching IndexedDB | maker's own recipe data |
| stored record -> DOM | Recipe, version, batch, step and note text render as React text, never markup | maker-authored text |
| stored id -> route and href | Every link and redirect is built by notebookPath, which encodes each segment | recipe, version and batch ids |
| repository source -> seed | Transcribed Ice Ed data enters app data modules and the seed | recipe data |
| probe harness -> localhost | Playwright probes serve boards and the build on 127.0.0.1, ephemeral ports | none leaves the machine |
| preview --host -> LAN | Device UAT serves the static build to Mark's network | static build, no data |
