### Judgement calls

8. **The version's plan keeps the typed 45 min / 75 °C; the batch records the ink overwrite as a step change, not a rewritten plan.** The printout shows both numbers struck and replaced by hand — the `.ier` export (saved before the overwrite) still carries the original typed values, which is what a maker planned before churning. The overwrite is what was actually done, which belongs on the batch record, not the recipe's own plan.
9. **"Double Recipe" recorded as every row's as-made value at plan × 2, with a note stating the rule**, rather than inventing a doubled formula on the version itself (the version's own rows keep the single-recipe plan the printout's table shows) or leaving the doubling unrecorded. Flagged for Mark: confirm this reading of "Double Recipe" is correct — the alternative would be a version-level note only, with no as-made values at all.
10. **Three battery marks set from the ink text, each an interpretation:** "Sweetness Good" → sweetness 3 (right); "Hard straight from Freezer" → hardness 5 (hard); "But scoopable" → scoopability 3 (right — read as neither crumbly nor gummy, following the binder audit's own reading of this line). None of these map without some interpretation; flagged for Mark to correct if any reads wrong.
11. **No draw temperature or churn duration recorded.** "40+ minutes to Churn" is inexact (open-ended) and is kept as prose in `atTheMachine`, not coerced into a number for `churnDurationMinutes`.
