# Phase 03.6 Plan 02: Line-only pen draft and save Summary

The pen's draft, dirty check, save and blocked-save check now carry removal on the lines alone: pressing "remove Whole milk, Step 2" and saving hands the repository a child whose Step 2 line is `removed: true`, Step 3 is `removed: false`, every row flag is `false`, and the parent is untouched.

## Accomplishments

- Task 1 (tracer): `handleStartDeveloping` seeds each draft line from `isLineRemoved(row, portion)` and keeps no row flag, so a stored older whole-row flag opens as every line out and is clean until the maker changes something. `isPenDraftDirty` compares each line's flag only. The `draftVersion` builder and `buildPenFields` write `removed: Boolean(draftPortion.removed)` per portion and `removed: false` on the row. `toggleDraftRowLines` is exported and pure (all out puts all in, otherwise all out) and `handleTogglePenRowRemoved`, now the orphan flag's handler only, calls it. `findBlockedRow` skips a removed line and judges the rest, so a split row with one line out and the other blank still blocks and names the row, and a row with every line out blocks nothing; the message strings are unchanged.
- Task 2: `IngredientTable` pen branch reads `penDraft.rows[id].portions[i].removed` alone (`lineOut`, and `GramsCell`'s forced strike, which no longer takes an `out` prop). The orphaned-row flag renders on the first line still in.
