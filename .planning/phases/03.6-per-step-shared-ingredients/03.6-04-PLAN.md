<decisions_recorded>
1. **The line descriptor.** For each stored line of the current row, in index order: `{ index, step, gramsFrom, gramsTo, gramsChanged, shareFrom, shareTo, shareChanged, removed, removedChanged }`. The baseline line is the baseline row's portion at the same index. A row absent from the baseline, or a baseline row with fewer portions, gives the null-from, changed-true shape the row descriptor already uses for a missing baseline, and never throws (T-03.6-07). `shareFrom` is the line's own grams over the baseline's active mass and `shareTo` its own grams over the current active mass, both through `formatShareOfBatch`, as the row-level fields are but per line. `removed` is `isLineRemoved(row, portion)` for the current line and `removedChanged` compares it with the baseline line's.
2. **Matching by index is right here.** The pen never changes a line's step (LD-02) and never adds or removes a portion, so a child's lines align with its parent's by index.
3. **`openingActiveById` and `openingMass`.** The table reads the figures a struck line shows from the version the comparison opened on: `baselineVersion` when the page gives one (the parent, while Show changes is on), otherwise the table's own `baselineActiveById` and `baselineMass` (the version the pen opened on). Plan 01's struck-line portion line in the pen moves onto the same two names, so one rule serves both states and the 86.3% fix is one fix.
4. **Per-line cells serve every row.** A one-line row has one line whose figures equal its row's, so the show-changes branch drops its `isSplit` fork and reads the line descriptor for every row. The one-line markup is unchanged and the existing show-changes cases pin it.
5. **The accessible label** reads off the line with the one-line row's own formula, unchanged: a 'was X g, now Y g' phrase when the line's amount changed or the line is out and has a baseline amount, a 'was A, now B' share phrase when the line is in and its share changed, and 'removed' last when it is out. (A removed one-line row's label keeps the 'now' phrase it has today, so its markup stays byte for byte.)
6. **A line that is in reads the lines still in over the current batch**: `formatPortionLine(line.gramsTo, rowGrams(liveRow), baselineMass)` with `liveRow` from the table's `baselineActiveById` (in Show changes the table's `rows` are the current version, so that Map and `baselineMass` are the current ones).
</decisions_recorded>
