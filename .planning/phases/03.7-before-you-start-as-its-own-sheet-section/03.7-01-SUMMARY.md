# Phase 03.7 Plan 01: Before you start as its own Sheet section Summary

**Before you start is its own Sheet section above the Ingredients (sketch 011 decision 36, placement B, H1, pen E2), drawn only with notes in reading and always in the pen, and the Instructions leave reading when a version has no steps.**

## What was built

- **Task 1 (tracer, ec064cb).** `RecipePage.jsx` renders `section.before-region` between the band and the Ingredients, holding the `h2.region-name` and `NoteList` (listKey `beforeYouStart`, the page's own pen handlers). `Method.jsx` lost its `method__before` block, its three note props and the `NoteList` import; `showsMethodRegion` takes `{ mode, steps }`. `app.css` carries the four-way areas at both widths (`recipe-page--no-before`, `--no-method` and the double modifier), the four row sets from 984 with the `1fr` still on the Instructions' row (or the Ingredients' row with none), `.before-region`, and no longer the old graduation-weight hairline. The new `RecipePage.beforeYouStart.test.jsx` mounts the whole page over a repository stand-in serving Olive Oil v1, Mexican Chocolate v3, Standard Base v2 and a constructed notes-only version (cases a to f).
- **Task 2 (fab06c9).** `beforeRegionShown` is also true in the pen; `NoteList` renders only when there are notes, so the pen with no notes draws the heading alone (E2). Six pen behaviours pinned: fields and remove (tabIndex 0) inside the section, an edited note reaching `saveVersion`, remove leaving one field, Tab order (Sheet title and description, then notes, then the first ingredient input), E2 on Mexican Chocolate v3 with Cancel back to reading, and Standard Base v2's two headings in order.

The existing pins that moved were rewritten in `cross-cutting.test.js` (983.98px block, decision 49 A rows, a `.before-region` rule test), `RecipePage.test.jsx` (the 261003-9bz source pins) and `Method.test.jsx` (the Before you start block replaced by one negative test; `showsMethodRegion` cases C and G updated, the hidden list still the same nine versions).
