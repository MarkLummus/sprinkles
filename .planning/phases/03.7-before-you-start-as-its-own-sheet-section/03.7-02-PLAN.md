Plan 03 words this as an open row for Mark and plan 04 records it in Phase 4's context.

4. **The group rule only applies from two groups up.** `.ingredient-table tbody:not(:only-of-type)` takes `break-inside: avoid`; a lone group splits between rows by the browser's default (Mark's answer 3), and a group taller than a page splits whatever the rule.
5. **The head stays in print at any page width.** The list-form table rules move from the phone-forms block into a new top-level sibling block, `@media screen and (max-width: 723.98px)`, placed directly after it, so print always draws the column form the print boards draw.
