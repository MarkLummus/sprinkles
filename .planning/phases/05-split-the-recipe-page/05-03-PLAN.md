<interfaces>
The hook contract this plan builds (plain JS, no TypeScript). Every executor task works against it:

usePenDraft() returns an object:
  penDraft            null or the pen's draft object
  blockedMessage      null or the blocking sentence
  blockedTarget       null, or { kind: 'versionLine', attempt }, or { kind: 'row', rowId, index, attempt }
  edit(op, ...args)   clearBlock(); setPenDraft((prev) => op(prev, ...args))
  open(version)       setPenDraft(penDraftFromVersion(version)); clearBlock()
  close()             setPenDraft(null); clearBlock()          (Cancel and both saves)
  restore(payload)    setPenDraft(payload); clearBlock()       (the kept-draft restore)
  checkSave(version, scopedVersions) returns { blockedKind, fields }:
      blocked:  sets blockedMessage and blockedTarget with attempt = ++blockedAttemptRef.current,
                returns { blockedKind: 'versionLine' or 'row', fields: null }
      clear:    returns { blockedKind: null, fields: penFieldsFromDraft(penDraft, version) }
  private clearBlock()  setBlockedMessage(null); setBlockedTarget(null)   (the only two null-resets in the file)

Existing pure functions this plan calls (from earlier plans and app/src/domain/lineage.js):
  penDraftRow(penDraft, rowId), toggleDraftRowLines(draftRow), restoreStepFromVersion(penDraft, version, stepN)   (penDraft.js, Plan 02)
  blockedSaveMessage(penFields, version, versions) -> string or null
  blockedSaveRowId(penFields, version, versions) -> row id or null
  blockedSaveLineIndex(penFields, version, versions) -> index or null
  parseGramsDraft(value) -> number or null                                                          (lineage.js)
  isLineRemoved(row, portion)                                                                        (rows.js)
