## Cut discipline (D-03, D-04): every cut task in this phase

- Cuts land in the D-03 order, one commit per cut (`refactor(08-NN): …`). A cut's commit holds the new module, the shell's edits, that job's shell-test entry and any D-11 re-point the cut forces, and nothing else.
- Move, do not redesign: every moved line stays byte-identical except names it now receives as arguments. Comments travel with their code. Handlers stay plain functions recreated each render, with no `useCallback` or `useMemo`. Dependency arrays are copied verbatim: the project has no ESLint, so nothing flags an incomplete array, and the incomplete ones are deliberate. Ids (`freshId()`) and instants (`new Date().toISOString()`) stay inside handlers and effects, never at render: the walk counts ids, so an extra id at render shifts every later id and the walk reports DIFF.
- Every hook is called above `if (loadFailed) return`. A hook body never dereferences `version`, `versions` or `batches` at its top level (they are `undefined` or `[]` while loading); only handlers and effects that already wait on a guard do.
- Prune imports a cut leaves unused in the same commit; the shell test's unused-import check fails the cut otherwise.
- Green means `npm --prefix app test` passes with no test deleted, skipped or weakened, and `sh .planning/phases/08-split-the-recipe-page-along-its-jobs/08-walk-check.sh` ends `MATCH 94 snapshots`.
- A cut that is not green after the node-repair budget is restored to the last green commit (`git checkout -- app/` and delete the cut's untracked new files), its failing output goes under "Cut not landed" in the SUMMARY, and the plan stops without attempting later cuts. The phase stays open until all six required cuts have landed (D-04); the orchestrator plans the retry.
- One Vite process per workspace: the walk check runs one-shot `vite build` into a scratch directory. Never start `npm run dev` or `npm run preview`, never build into `app/dist` (Mark's own `vite preview --host` serves it).
- In a fresh worktree `app/node_modules` is absent (gitignored): run `npm --prefix app ci` first.
