## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| editor to store | a draft the maker typed becomes stored records |
| other tab to store | a second tab can record a batch or a child between Edit and Save-over |
| stored ids to address | a stored id becomes a URL segment |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-07 | Tampering | a partial Save leaving a recipe without its version | high | mitigate | createRecipeWithVersion is one transaction with a hand abort; forced-failure, collision and existing-id tests leave every store as before |
| T-11-08 | Tampering | Save-over writing over a version that gained a batch or a child in another tab | high | mitigate | firstVersionRefusal runs inside saveFirstVersionOver's own transaction read; the business refusal writes nothing and keeps the edit draft |
| T-11-09 | Tampering | Save-over changing a printed Sheet code | high | mitigate | a different sheetCode or createdAt is a TypeError; sheetCodeProblems runs inside the transaction; the test asserts the same code after save-over |
| T-11-10 | Denial of service | a saved recipe whose export cannot be imported | medium | mitigate | creation-roundtrip.test.js proves a created version with steps, split and unplaced rows, scales, problems and targets passes validateStoreFile |
| T-11-11 | Tampering | an edit draft taken for a create draft or a pen draft (deleted or restored into the wrong editor) | medium | mitigate | kind 'edit' with its own draftMatchesEdit; draftMatchesCreate and draftMatchesVersion refuse it by kind |
| T-11-12 | Tampering | a stored id with '/' or '..' in the edit address | low | mitigate | editPath is built on notebookPath, which URI-encodes each segment |
| T-11-SC | Tampering | npm/pip/cargo installs | low | accept | no package is installed |
