# 260917-h83 — Context (locked decisions)

Mark asked for this on 2026-09-17, immediately after 260917-gjo (`4bcac2f`) landed the shared
`--gap-page` token. It closes the one gap that task recorded and deliberately left.

## The defect

Every other route now shares one left edge through `--gap-page` — 48px by default, 20px below 600px.
Four boxes read it: `.recipe-page`, `.running-head`, `.page-status`, `.not-found`.

The recipe **list** route does not. `RecipeList.jsx` returns a bare fragment holding
`.recipe-list__transfer` and `<ul class="recipe-list">`, and neither carries inline padding
(`app.css` ~368 and ~389), so the list sits flush against the viewport edge at every width. It is the
app's entry screen, and it is the one route that looks unframed.

## The fix

Give the list route the same gutter, reading the same `--gap-page` token. Never a fresh value, never
a literal, never a second copy of the 600px breakpoint. One value app-wide is this project's standing
rule; `4bcac2f` is what made it true, and this extends it rather than forking it.

How to apply it is the planner's call, but weigh:

- **A wrapper element** around the list route's content is the obvious shape, mirroring
  `.recipe-page`, which is itself a padded page-body element. If one is added, name it so it reads as
  the list's page body, not a generic container.
- **Padding on `.recipe-list` alone would miss `.recipe-list__transfer`**, which sits above it in the
  same fragment and needs the same edge.
- **Do not reach for the routed shell.** `RecipeList` is mounted directly
  (`{ path: '/', Component: RecipeList }`), not through `RecipePageForRoute`. Rewiring the routing to
  share a shell is a structural change nobody asked for.

## Explicitly out of scope

**The running head.** The list route has none today, and that is defensible — the head is the link
home, and on the list you are already home. Mark asked for the gutter only. Do not add a running
head, do not add a page-status region, do not touch `router.jsx`.

## Constraints

- No literal. Every value reads a custom property.
- No colour change, no motion, nothing moves on focus, hover or selection.
- Do not touch the batch pen, the version pen, the churn-date wiring, `PenFoot`, or which channel any
  sentence uses.
- Do not edit anything under `.impeccable/` or `DESIGN.md` — those belong to the orchestrator.
