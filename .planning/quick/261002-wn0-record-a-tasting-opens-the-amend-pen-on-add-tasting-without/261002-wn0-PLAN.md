Settled from the briefs, the boards and the code (the planner's answers; they go in the SUMMARY for Mark):

- Heading. The pen says Correct in neither path. "Correct" is only the opener word on the log's head (BatchRow.jsx ~646-656, rendered only while no pen is open). Opened from Correct, the amend pen's head reads "Batch" and "churned {date}". Opened from Record a tasting it reads the same, unchanged. No board draws a different head for this path, so none is invented.
- Cancel. Either ceremony's Cancel discards the whole draft with no dialog (D-24) and returns focus to the band's Record a tasting: route-recipe-batch.md section 6, "Cancel returns focus to the control that opened the pen". Escape on an untouched pen does the same (D-27). Focus scrolls the band back into view, which "returns the maker to the band".
- Save batch writes the draft through the existing amend path (completeRecord on that batch, never a new batch). It announces "recorded ... against ..." and lands focus on the log's Batch heading in place: route-recipe-batch.md section 3, "a completing save lands on the saved record's heading ... The amend path never navigates and lands the same way in place" (Mark, 2026-09-16). The band's action then reads Record another.

The save button reads "Saving changes…" while it writes. Brief section 3 says "Adding a tasting is not an amendment". This was already true of Correct then Add tasting, and it is not changed here.
