<objective>
Put a remove link on every line of a split ingredient in the Next version pen, with each one removing the whole ingredient. Then fix the share a removed split ingredient's portion lines show. This is sketch 011 decision 44, with Mark's answers of 2026-10-04: "(1) B, a link on every line, each removes the ingredient. (2) The 86.3% fix goes in the same quick as the link."

Purpose: Mark found the gap on the iPad and iPhone. Whole milk's Step 2 line had a remove link and its Step 3 line did not, because IngredientTable.jsx renders the control on the first portion line only. A maker looking at Step 3 had no way to take the milk out. Option B puts the same control on every line, with the same word, position and effect, so nothing changes in the data model.

Sid also found a separate defect, which Mark put in this quick. After remove, a split ingredient's portion lines read "· 86.3% in all": the ingredient's grams measured against the batch without it. The struck % of batch beside them is right (46.3%).

- a jsdom click test
- a probe that measures the built app before and after in WebKit, coarse and fine, at 393, 1366 and 1600, and checks it against split-remove-link.html's B panels
- a SUMMARY with the numbers
