# Phase quick-261005-t32 Plan 01: The blocked-save sentence in the blocked line Summary

On Olive Oil v1, Next version, with Whole milk's Step 3 amount cleared, Save as a new version now prints "Whole milk needs an amount, or remove it" last in the Step 3 line's name cell, under its portion line, with the field marked invalid and described by that sentence.

## What changed

- `app/src/ui/RecipePage.jsx` (one line): the IngredientTable call site passes `blockedRowMessage={blockedTarget?.kind === 'row' ? blockedMessage : null}` beside `blockedRowId`. Nothing else in the file changed: not `buildPenFields`, not the announce call, not the status line, not the version line's props.
- `app/src/ui/IngredientTable.jsx`:
  - imports `FieldFeedback` and defines one constant id, `BLOCKED_ROW_ERROR_ID = 'ingredient-field-error'`.
  - a `blockedRowMessage = null` prop, commented with decision 57.
  - in `renderDevelopingEntry`, `blockedSentence` is the message when `isBlocked` and null otherwise. A `<FieldFeedback error={blockedSentence} errorId={...} />` is the last child of the name cell, after the portion line on a split line and after the remove control on a one-line row.
  - `GramsCell` takes `errorId = null`. The pen input carries `aria-invalid={errorId ? 'true' : undefined}` and `aria-describedby={errorId ?? undefined}`, mirroring VersionRow's version field. The read-only branch is untouched.

Why typing clears the sentence with no new code: `handleChangePenGrams` already sets both `blockedMessage` and `blockedTarget` to null, so `blockedRowMessage` turns null, the span is not rendered, the two attributes go, and the outline goes, in the same render.

Why the status line stays empty for a line: `buildPenFields` calls `announce(VERSION_BLOCKED_STATUS)` only when there is no row. That code is unchanged.

## Choices at my discretion

- Reused `FieldFeedback` rather than a hand-written span: it renders exactly `<span id class="field-error">`, the same component the version line uses, and it takes React text children only (no raw HTML path).
- One constant id, as the version line has one `version-field-error`: only one line is blocked at a time.
