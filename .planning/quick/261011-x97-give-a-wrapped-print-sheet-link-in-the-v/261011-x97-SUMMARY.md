## The fix

In `app/src/styles/notebook.css`, inside the existing `@media (pointer: coarse)` block, after the notebook fields' rule:

```css
.notebook-version__acts > a.notebook-link {
  min-height: var(--touch-min);
}
```

It is preceded by a comment naming Mark's 04-09 rule and the measured 724 wrap. Chrome 724 fine keeps its 17px link, because the floor follows the pointer only. Where the link shares a line the row already stretches it to 44px, so the rule changes nothing there.

`notebook.test.js` gains a describe block of four tests (the coarse rule's single declaration; app.css's button floor uses the same condition and token; the link's rules are `[undefined, '(pointer: coarse)']`; exactly one `notebook-link` rule declares a min-height). Tests 1, 3 and 4 failed before the rule (Test 2 passed as planned). The ordered media-step test is unchanged and green.
