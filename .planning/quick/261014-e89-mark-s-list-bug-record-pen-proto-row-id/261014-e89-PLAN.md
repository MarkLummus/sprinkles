<objective>
Close the Mark's List bug `bug-record-pen-proto-row-id` (WR-01 of `.planning/phases/05-split-the-recipe-page/05-REVIEW.md`). A stored row id of `__proto__` loses the as-made grams the maker types. The record pen's as-made map is written with bare bracket assignments through the row id, so the id `__proto__` calls the prototype setter instead of creating a key. The typed grams vanish, the pen reads clean, and Save drops the figure. The fix has two parts:

- Build every as-made map with own-property-safe, order-keeping builds. The model is `penDraftFromVersion` / `penDraftRow` in `app/src/domain/penDraft.js` (T-05-04).
- Refuse the reserved names `__proto__`, `constructor` and `prototype` as row id values on import, so such an id cannot enter the store in the first place.
