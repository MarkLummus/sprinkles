## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| /impeccable live wrong-file scaffold match | The live-mode picker's text-similarity wrap matched the wrong file twice — once a different sketch (005 instead of 007), once real production code (`app/src/ui/BatchRow.jsx`) instead of the static sketch HTML being edited | advisory | Verify the scaffold's target `file` field before writing on every live-mode event; if it doesn't match the sketch you're pointed at, reply `error` and don't write. Both misfires were caught and reverted cleanly this session, but this is worth watching for again if live mode is retried on this file. |
| CSS asserted equal ≠ CSS rendered equal | Two elements with identical coded margin values were not actually equal on screen (grid vs. flex-column margin inclusion differs; `border-width` fractional values silently round on `<input>`/`<textarea>` in Chrome) | advisory | Always measure with `getBoundingClientRect()` / `getComputedStyle()` in a real browser before calling a spacing question resolved — reasoning from the CSS source alone missed several real bugs this session (double margins, a stray UA `<p>` margin, a 1.5px border silently becoming 1px). |
