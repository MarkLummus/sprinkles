# Sketch 006: Light tasting entry

## Design Question
Raised by Mark 2026-09-10, looking at sketch 005: the recording pen already ran as long as the ingredient table with just the primary tasting folded in. Sketch 004 trims a light "taste again" entry down to three fields (date, marks, one note line), but marks are still marks — the six-axis block (four core plus two declared) is the one thing 004's trimming doesn't touch, and it was the single biggest contributor to 005's length. This sketch isolates the entry pen for a light tasting and tests how much air comes out of the marks block itself, independent of which fields surround it.

## Variants
- **A: Same full treatment as the primary** — each axis keeps its label, anchor words, and a row of nine stops, stacked six deep. The baseline: identical to how marks read in the primary tasting (sketch 005), so the comparison is apples to apples.
- **B: One compact row per axis, no anchor words** — label and stops share one line; the anchor words (the teaching device — "spoon sinks … spoon won't enter") drop out, on the reasoning that by a fourth taste the maker already knows what the scale means.
- **C: Pick which axes apply, then mark those** — a row of six chips lets the maker tap only the axes that changed this time; only picked axes expand into a mark row. Nothing to fill in for an axis you don't tap.

## What to Look For
- Use "Toggle 100px ruler" (bottom bar) to compare each variant's total height against 005's already-too-long pen — is B or C actually shorter, or does it just look denser?
- In B, does dropping the anchor words lose something real, or was that scaffolding only the first tasting needed?
- In C, does picking axes first feel like an extra step that slows down a "quick" entry, or does it read as the maker's own judgment about what's worth remarking on this time?
- If none of the three gets meaningfully shorter, that's itself a finding: the fix for "wall of text form" may not live in the marks control at all, but in how many axes exist or whether every axis is asked for every tasting.
