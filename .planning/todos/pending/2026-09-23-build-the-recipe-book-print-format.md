## Problem

Mark wants two print formats because their uses differ (2026-09-23): the Notebook format
(the bench sheet, Phase 4) and a Recipe book format for making a finished recipe. Phase 4
builds only the Notebook format (04-CONTEXT D-22). The Recipe book format carries no batch or tasting log (Mark, 2026-09-23).

## Design

Drawn on Mark's Sprinkles canvas, page "Print formats", artboard `RecipeBookSheet.dc.html`
(https://claude.ai/artifact/JHwDoAYHDf9yQ1CcUZyATq), seeded by the Recipe book page's
"Print and make" and recipe-route artboards and Mark's note there. Not yet approved.

## Open before building

- Prep and cook times have no home in the data; the drawn strip uses only the version's own targets.
- Where it prints from: the Recipe book route is a placeholder today.
- Whether both formats share one sheet code (04-CONTEXT D-22a).
