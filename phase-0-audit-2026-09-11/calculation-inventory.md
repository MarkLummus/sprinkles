## Coefficient ownership

`app/src/data/library.js` is the active seed source, not a live dependency of historical calculations: `data/olive-oil.js:36` clones ingredient records into each row. `domain/lineage.js` carries coefficient metadata and clones data when making versions; `domain/batch.js:createBatch` snapshots rows and set ID. `composition.js:12` labels one global set `2026.1-slice-transcription`, but does not use a registry or dispatch on record IDs. Disposition: **move/refactor** scientific constants into versioned engine tables; **reuse** embedded maker-data/provenance ownership in Sprinkles. Tests: `composition.test.js` embedding invariant, `batch.test.js` snapshot isolation, `lineage.test.js`, `store/transfer.test.js`. Import currently rejects null composition; DB upgrade currently resets prior stores (see main report).

## Searched but not implemented in the active application

- Protein, explicit water/lactose component composition, individual sugar-system accounting, syrup active-mass conversion, dextrose form distinction, ethanol PAC/PRS, component overrides/contributions: absent as active calculation modules.
- Premix decomposition, stabilizer-to-water dosage, exposed emulsifier/stabilizer totals: absent beyond the internal solids terms above.
- Quantitative coverage, independent coefficient/model versions, stable calculation IDs, structured engine warnings, candidate result envelope and complete planned-versus-actual composition deltas: absent. Existing pure editing comparison is a starting seam, not this API.
- Overrun is entered/stored as `churn.overrunPercent`, not calculated. `batch.js`, `BatchRow.jsx`, `RecipePage.jsx`, and transfer validation preserve null versus zero. Tests: `batch.test.js`, `BatchRow.test.jsx`, `RecipePage.test.jsx`, `transfer.test.js`. Disposition **out_of_scope**; keep maker observations in Sprinkles.
- No active physical freezing-point/curve, frozen-water, hardness, scoopability, sensory prediction, optimization or density conversion algorithm found. Sensory axes are maker observations. `densityGPerMl` exists in the seed but has no active conversion consumer.
